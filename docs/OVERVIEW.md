# 功能总览（OVERVIEW）

## 这是什么

一个 ComfyUI 自定义节点插件：把浏览器单文件工具《ANIMA提示词生成器.html》的
「词库 + 随机 + 自检」搬进工作流，并补上源脚本缺的四块能力 ——
**分级、先收敛后抽取、可调权重、结果可复现**。

生成的是**提示词文本**（英文 danbooru 标签串 + 中文摘要报告），不生成图片、
不联网（抓取类工具脚本除外）、不调用任何大模型。

## 四个节点

| 节点 | 一句话 |
|---|---|
| Anima 提示词随机生成（V3） | 主力：按档位抽一段完整正文，`seed=-1` 每次重抽 |
| Anima 提示词分级审查（V3） | 对任意提示词判定实际落档（1–4 级 + 命中分类明细） |
| Anima 提示词拼接台（V3） | 随机结果 + 手写补充按档位上限合并 |
| Anima 提示词检查与修复（V3） | 任意提示词跑同一套 17F/10S 自检并自动修 |

配套前端面板（节点按钮「⚙ 打开随机面板」）：三层权重编辑、角色库
（2300+ 角色 / 作品筛选 / 收藏 / 预设 / 自定义角色 / 随机池）、
场景搭配（122 条按档位分组）、字段联动预检、免责弹窗。

## 核心机制

- **五级档位闸门**：候选池先按档位收敛 → 抽取 → 体检 → 超档回滚；低档绝不越界。
- **三层权重**：段 / 字段 / 选项，0 = 关闭，3.0 = 必现；「我选择的要固定，没选的才随机」。
- **角色对齐**：选中角色后发色 / 瞳色 / 特征标签随官方设定对齐；多人时自动降级。
- **场景搭配**：整字段固定配方（`place` / `pose` / `emotion` 等组合），套用字段不参与随机。
- **字段联动**：体位配对 / 表情配套 / 场景倾向三张可解释的表，抽中 A 后把矛盾 B 剔掉。
- **可复现**：同 seed 同设置结果逐字一致；报告（report 端口）写明每一步做了什么。
